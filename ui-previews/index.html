Smart Bookmark — 风格预览

3 directions · pick one

以下是3个差异化方向，共同基调是极简精致（Linear / Vercel 感），但在色彩、版式与质感上各走一条路。每版都用同一组场景演示（默认列表、编辑模式、搜索入口、设置卡片），便于直接对比。 选定方向后，再把它套到所有5个界面（popup / settings / quickSearch / quickSave / intro）上，并修复复选框遮挡 favicon、数字字号失控、设置页风格脱节这三个具体问题。

Variant A

Mono Editorial

近乎无色彩，靠字体层级与负空间说话。
  • 主字体 Inter / SF Pro，标题用衬线点缀
  • 选中态用反色块（黑底白字），不用蓝
  • 分隔线 1px hairline；圆角 8px
  • 气质：编辑部、纸面、克制

Variant B

Nordic Precision

冷灰冰蓝、几何感强。最贴近Vercel / Geist。
  • 无衬线纯净字体，标题字距收紧 -0.02em
  • 焦点色 #1f6feb 极少量出现
  • 选中态用淡蓝填充 + 1px 蓝色描边
  • 气质：工程师、精密仪器、冷静
打开 Variant B
Variant C

Soft Mono + Accent

中性灰底 + 单一焦点色（电光绿）。
  • 暖中性背景比 A/B 稍暖，但不复古
  • 焦点色只出现在选中、计数高亮、关键按钮
  • 圆角 10px，比 A 略软
  • 气质：极简但有温度，对比强烈
打开 Variant C
